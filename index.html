Arquitetura & Infraestrutura — Diozz

Stack pensada para carregamento rápido no mobile, suporte a vídeos/imagens via CDN e sincronização em 2 fases (API FácilZap -> Banco Próprio).

1. Front-end

Next.js + TypeScript + Tailwind

SSR/ISR para SEO, vitrine editorial minimalista, zoom nos cards, galeria com vídeo MP4 e persistência local do carrinho.

2. Back-end & Tempo Real

Node.js + SSE / WebSockets

Checkout enxuto (Nome + Telefone), geração de Romaneio em PDF, controle de acesso (Admin vs Vendedor) e notificação global.

3. Filas & Cache

Redis + BullMQ

Disparo automático via WhatsApp após X minutos se o cliente deixar peças no carrinho sem finalizar.

4. Mídia & Dados

PostgreSQL + CDN (Vídeos/Fotos)

Fase 1 conectada à api.facilzap.app.br; Fase 2 100% no PostgreSQL próprio com Cloud Storage para vídeos MP4.
